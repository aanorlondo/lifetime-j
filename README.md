# Life Time Counter

Une application web minimaliste et légère qui affiche l'écoulement du temps en temps réel (années, mois, jours, heures, minutes, secondes) depuis une date clé.

## 🚀 Démo en ligne

La page est déployée et accessible ici :  
👉 **[https://aanorlondo.github.io/lifetime-j/](https://aanorlondo.github.io/lifetime-j/)**

## 🛠️ Stack technique

- **HTML5** : Structure sémantique
- **CSS3** : Flexbox / Grid & effet *glassmorphism*
- **JavaScript (Vanilla)** : Calcul dynamique et précision temporelle sans dépendance externe
